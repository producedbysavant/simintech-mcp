# Запуск расчёта и чтение сигналов

## Инструменты

| Инструмент | Назначение |
|---|---|
| `run(to_time=N)` | Расчёт до момента N секунд |
| `run()` | Запуск без ограничения времени |
| `step(n)` | N шагов расчёта |
| `stop()` | Остановить |
| `get_time()` | Текущее модельное время |

Порядок: `run(to_time=10)` → `get_signal("Блок")` → `get_time()`.

## Сигналы читаются по имени БЛОКА

**Ключевая особенность.** `GetProjectSignalList` (COM) возвращает **только
обменные сигналы** — те, что созданы блоками «Вход/Выход алгоритма». В
обычной модели таких блоков нет, и список будет **пустым**. Это корректное
поведение COM, а не ошибка модели.

Для доступа к сигналам обычных блоков используется XML-представление проекта
(`.xprt`): `Project.list_signals()` при пустом COM-списке экспортирует проект
и разбирает имена блоков.

**Имя сигнала блока = имя блока.** Поэтому:

```
add_block "Усилитель" name="Gain" props="a=2"
get_signal("Gain")      # прочитает сигнал блока Gain
```

Не пытайтесь искать сигнал по имени свойства или по внутреннему имени выхода —
используйте `Name` блока. Задать его: `set_property("Name", ...)` или
параметр `name=` в `add_block`.

## Данные расчёта

`get_signal` возвращает **текущее** значение сигнала. Сборка кривой по
времени — это последовательность `step()` + `get_signal()` в цикле;
готового инструмента выгрузки массивов нет.

`Simulation.run()` в библиотеке — это только флаг `ProjectRun`: он запускает
расчёт и сразу возвращает управление, не дожидаясь окончания и не возвращая
данных. Для детерминированного результата используйте `run_to(N)` — он
дожидается достижения момента (`RunTo` + `WaitForTime`).

## Порядок имеет значение

Параметры блоков нужно устанавливать **до** запуска расчёта. Блоки вроде
«Константа» инициализируются в момент `ProjectStart`, поэтому `set_block_param`
во время расчёта может не дать эффекта. Инструмент переинициализирует блок
(`InitBlock`), но надёжнее менять параметры до `run`.

## Платформа

COM API SimInTech работает только на Windows и требует зарегистрированного
сервера (`mmain.exe /regserver`). На других платформах `status()` вернёт
сообщение о несовместимости, а расчётные инструменты — ошибку.
