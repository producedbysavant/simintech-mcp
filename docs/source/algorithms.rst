Алгоритмы размещения и трассировки
===================================

Полное описание — в ``docs/algorithms.md`` (Markdown). Здесь — краткая
справка и документация модулей.

LayeredPlacer
-------------

Размещение блоков слоями по направлению сигнала (адаптация Sugiyama для
горизонтального потока слева направо):

1. **Ранжирование**: блоки без входов → слой 0; далее N+1 по правилу «все
   входы из слоёв ≤ N, хотя бы один из N». Обратная связь/чистый цикл —
   корень = блок с минимумом входов.
2. **Упорядочивание**: медианная эвристика (минимизация пересечений).
3. **Координаты**: X по слою (``layer_gap``), Y с равными промежутками
   (``block_gap``), вертикальное центрирование колонок.

AStarRouter
-----------

Ортогональная трассировка линий на дискретной сетке:

1. **Сетка**: шаг ``grid_size`` (20 px); блоки — прямоугольники с отступом
   1 узел (margin), чтобы линии не шли вплотную.
2. **Вылет из порта**: точка по нормали к стороне порта на расстоянии
   ``2×grid_size`` (проходит сквозь margin-зону блока).
3. **A***: движение по 4-соседям, штраф за повороты, старт/цель всегда
   проходимы (порты на границе блоков).
4. **Спец-случаи**: свободная прямая → ``[]`` (прямое соединение);
   невозможный путь → ``LayoutError``.
5. **Сглаживание**: удаление коллинеарных точек.

ObstacleGrid
------------

Дискретная сетка препятствий с конверсией «координаты схемы ↔ узлы сетки».
