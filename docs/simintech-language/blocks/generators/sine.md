# Блок «Синусоида» (Sine)

Генерирует гармонический сигнал синусоидальной формы.

## Назначение

Блок «Синусоида» формирует непрерывный гармонический сигнал вида `A * sin(2*pi*f*t + phi)`. Используется как тестовый сигнал для частотного анализа (АЧХ, ФЧХ), моделирования колебательных процессов, генерации несущей частоты в системах связи.

## Входы и выходы

| Тип | Имя | Описание |
|-----|-----|----------|
| Вход | — | Нет входов |
| Выход | y | Синусоидальный сигнал, double |

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| A | double | 1.0 | Амплитуда |
| f | double | 1.0 | Частота, Гц |
| phi | double | 0.0 | Начальная фаза, рад |
| bias | double | 0.0 | Постоянная составляющая |

## Математическое описание

```
y(t) = bias + A * sin(2 * pi * f * t + phi)
```

## Пример схемы: частотный анализ фильтра низких частот

Компоненты:
1. **Синусоида** (A=1.0, f=0.5) — входной сигнал низкой частоты
2. **Синусоида_2** (A=1.0, f=5.0) — входной сигнал высокой частоты
3. **Сумматор** — смешивает два сигнала
4. **Фильтр низких частот** (Передаточная функция: 1/(0.3s+1))
5. **Временной график** — 3 входа (смесь и отфильтрованный сигнал)

Связи:
```
Синусоида.y     →  Сумматор.in1
Синусоида_2.y   →  Сумматор.in2
Сумматор.y      →  ФНЧ.x
ФНЧ.y           →  График.y1
Сумматор.y      →  График.y2
```

Ожидаемый результат: на графике видно, что низкочастотная составляющая (0.5 Гц) проходит через фильтр практически без изменений, а высокочастотная (5 Гц) подавляется.

## Код на встроенном языке

```simintech
function SineGenerator
  input:
    double A = 1.0;
    double f = 1.0;
    double phi = 0.0;
    double bias = 0.0;
  output:
    double y;
  var:
    double t;
    double twoPi = 6.283185307179586;
  begin
    t = getCurrentTime();
    y = bias + A * sin(twoPi * f * t + phi);
  end;
```

## Варианты использования

- **Частотный анализ**: подавайте синусоиды разных частот на вход системы и анализируйте выход
- **Моделирование вибраций**: A — амплитуда вибрации, f — частота вращения
- **Биения**: сложите две синусоиды с близкими частотами (f1=10, f2=11) — получите биения с частотой 1 Гц
- **Модуляция**: используйте синусоиду как несущую, изменяя амплитуду внешним сигналом

## Предостережения

- При f=0 выход всегда равен bias (синус нулевой частоты — константа)
- Шаг моделирования должен быть не менее чем в 10 раз меньше периода сигнала (dt < 0.1/f), иначе форма сигнала искажается
- Начальная фаза phi задаётся в радианах, не в градусах — распространённая ошибка
- Для генерации косинусоиды задайте phi = pi/2
- При сложении нескольких синусоид с разными частотами убедитесь, что общее время моделирования кратно всем периодам — иначе на графике будут «обрубки»
