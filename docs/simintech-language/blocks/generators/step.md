# Блок «Ступенька» (Step)

Генерирует сигнал, изменяющийся скачком в заданный момент времени.

## Назначение

Блок «Ступенька» используется для подачи единичного ступенчатого воздействия на систему. Это базовый тестовый сигнал при анализе переходных процессов: по реакции системы на ступеньку можно определить время нарастания, перерегулирование, установившуюся ошибку и другие характеристики.

## Входы и выходы

| Тип | Имя | Описание |
|-----|-----|----------|
| Вход | — | Нет входов (независимый генератор) |
| Выход | y | Ступенчатый сигнал, double |

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| A | double | 1.0 | Амплитуда ступеньки |
| t0 | double | 0.0 | Момент времени срабатывания, с |
| y0 | double | 0.0 | Начальное значение (до t0) |

## Математическое описание

```
y(t) = y0,              t < t0
y(t) = y0 + A,          t >= t0
```

## Пример схемы: реакция звена первого порядка на ступеньку

Компоненты:
1. **Ступенька** (A=1.0, t0=0.5, y0=0.0) — входной сигнал
2. **Апериодическое звено 1-го порядка** (K=2.0, T=1.5) — исследуемая система
3. **Временной график** — визуализация

Связи:
```
Ступенька.y  →  Апериод_1.x
Апериод_1.y  →  График.y
Ступенька.y  →  График.x (опционально, для сравнения)
```

Ожидаемый результат: график показывает ступеньку в момент t=0.5 с и экспоненциальный отклик системы, стремящийся к значению K*A = 2.0.

## Код на встроенном языке

```simintech
function StepBlock
  input:
    double A = 1.0;
    double t0 = 0.0;
    double y0 = 0.0;
  output:
    double y;
  var:
    double currentTime;
  begin
    currentTime = getCurrentTime();
    if currentTime < t0 then
      y = y0;
    else
      y = y0 + A;
    end_if;
  end;
```

## Варианты использования

- **Единичная ступенька** (A=1.0) — анализ переходной характеристики
- **Включение нагрузки** (A=10.0, t0=5.0) — имитация подключения потребителя
- **Сброс возмущения** (A=-5.0, t0=2.0) — имитация снятия возмущающего воздействия
- **Задержанный старт** (y0=0.0, A=1.0, t0=10.0) — запуск процесса через 10 секунд

## Предостережения

- Если t0 меньше шага моделирования, ступенька сработает на первом же шаге
- При A=0 блок не генерирует ступеньку — сигнал остаётся равным y0 на всё время моделирования
- Для генерации последовательности ступенек используйте несколько блоков с разными t0 и сумматор
- В дискретных моделях ступенька может «проскочить» точку t0, если шаг квантования больше расстояния до t0
