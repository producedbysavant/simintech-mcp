# Блок «Константа» (Constant)

Генерирует постоянный сигнал заданной величины.

## Назначение

Блок «Константа» выдаёт неизменный во времени сигнал. Используется для задания уставок, коэффициентов, смещений, пороговых значений, опорных напряжений и других постоянных величин в модели.

## Входы и выходы

| Тип | Имя | Описание |
|-----|-----|----------|
| Вход | — | Нет входов |
| Выход | y | Постоянный сигнал, double |

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| value | double | 0.0 | Значение константы |

## Математическое описание

```
y(t) = value, для всех t
```

## Пример схемы: сравнение с уставкой

Компоненты:
1. **Ступенька** (A=5.0, t0=1.0) — имитация изменяющегося процесса
2. **Константа** (value=3.0) — уставка
3. **Сравнение** — блок RelationalOperator (>=)
4. **Цифровой индикатор** — отображение результата

Связи:
```
Ступенька.y    →  Сравнение.x1
Константа.y    →  Сравнение.x2
Сравнение.y    →  Индикатор.in
```

Ожидаемый результат: до t=1.0 сигнал ступеньки равен 0 (меньше уставки), выход сравнения — false (0). После t=1.0 сигнал становится 5.0 (больше уставки), выход — true (1).

## Код на встроенном языке

```simintech
function ConstantBlock
  input:
    double value = 0.0;
  output:
    double y;
  begin
    y = value;
  end;
```

## Варианты использования

- **Уставка регулятора**: задайте желаемое значение регулируемой величины
- **Коэффициент усиления**: подайте константу на второй вход блока «Умножение»
- **Смещение нуля**: прибавьте константу к сигналу через сумматор
- **Порог срабатывания**: подайте константу на вход сравнения для формирования логического сигнала
- **Время выполнения**: используйте константу с блоком «Таймер» для задания выдержки времени

## Предостережения

- Константа не меняется во времени — для изменения значения на ходу используйте блок «Ступенька» или генератор
- Не путайте блок «Константа» с параметром блока — параметр настраивается до старта моделирования, константа остаётся частью схемы
- Для подачи нулевого сигнала блок не обязателен — многие блоки допускают неподключенные входы, которые считаются нулевыми
- Если значение константы должно меняться между запусками модели, вынесите её в глобальную переменную или параметр схемы
