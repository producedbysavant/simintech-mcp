# Блок «Сумматор» (Sum)

Выполняет алгебраическое суммирование нескольких входных сигналов.

## Назначение

Блок «Сумматор» складывает, вычитает и комбинирует сигналы. Это базовый строительный блок любой системы управления: обратные связи, компенсация возмущений, смешивание сигналов, формирование ошибки регулирования.

## Входы и выходы

| Тип | Имя | Описание |
|-----|-----|----------|
| Входы | in1, in2, ... | Суммируемые сигналы, double |
| Выход | y | Результат суммирования, double |

Количество входов настраивается (от 2 до 10 и более в зависимости от версии).

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| signs | string | "++" | Знаки для каждого входа (+ или -) |
| numInputs | int | 2 | Количество входов |

## Математическое описание

```
y = sum(sign_i * in_i)    для всех i = 1..n
```

где sign_i = +1 для знака "+", -1 для знака "-".

## Пример схемы: ПИД-регулятор (формирование ошибки)

Компоненты:
1. **Константа** (value=100.0) — уставка
2. **Ступенька** (A=20.0, t0=3.0) — возмущение
3. **Сумматор** (signs="+-") — формирование ошибки: e = уставка - обратная связь
4. **Временной график** — отображение ошибки

Связи:
```
Константа.y     →  Сумматор.in1  (+)
ОбратнаяСвязь.y →  Сумматор.in2  (-)
Сумматор.y      →  График.y
```

Если signs = "++-", схема суммирует три входа: y = in1 + in2 - in3.

## Код на встроенном языке

```simintech
function SumBlock
  input:
    double in1;
    double in2;
  output:
    double y;
  var:
    string signs = "++";
  begin
    y = 0.0;

    if length(signs) >= 1 then
      if substr(signs, 0, 1) == "+" then
        y = y + in1;
      else
        y = y - in1;
      end_if;
    end_if;

    if length(signs) >= 2 then
      if substr(signs, 1, 1) == "+" then
        y = y + in2;
      else
        y = y - in2;
      end_if;
    end_if;
  end;
```

## Варианты использования

- **Ошибка регулирования**: `e = setpoint - feedback` (signs = "+-")
- **Смешивание сигналов**: `y = signal1 + noise` (signs = "++")
- **Компенсация**: `y = command + disturbance_compensation` (signs = "++")
- **Взвешенная сумма**: с блоками усиления на каждом входе
- **Дифференциальный сигнал**: `y = in1 - in2` (signs = "+-")

## Предостережения

- Количество знаков в параметре signs должно совпадать с числом подключенных входов
- Если вход не подключен, его значение считается нулевым — но лучше явно ставить константу 0
- При signs = "+" (один вход) блок работает как повторитель
- Большое количество входов снижает читаемость схемы — для сложных комбинаций используйте каскад сумматоров
- Знаки задаются строкой без разделителей: "+-+" — правильный формат, "+ - +" — неправильный
- При signs = "--" выход инвертирует сумму: y = -in1 - in2
