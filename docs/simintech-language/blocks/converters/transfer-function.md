# Блок «Передаточная функция» (Transfer Function)

Реализует линейное динамическое звено, заданное передаточной функцией в виде отношения полиномов.

## Назначение

Блок «Передаточная функция» моделирует линейную динамическую систему вида:

```
W(s) = (b_m * s^m + b_{m-1} * s^{m-1} + ... + b_0) / (a_n * s^n + a_{n-1} * s^{n-1} + ... + a_0)
```

Это универсальный блок для описания любых линейных звеньев: апериодических, колебательных, форсирующих, интегрирующих, дифференцирующих.

## Входы и выходы

| Тип | Имя | Описание |
|-----|-----|----------|
| Вход | u | Входной сигнал, double |
| Выход | y | Выходной сигнал, double |

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| num | double[] | [1] | Коэффициенты числителя [b_m, b_{m-1}, ..., b_0] |
| den | double[] | [1, 0] | Коэффициенты знаменателя [a_n, a_{n-1}, ..., a_0] |

## Примеры передаточных функций

### Апериодическое звено 1-го порядка

```
W(s) = K / (T*s + 1)
```

Параметры:
- num = [K]
- den = [T, 1]

Реакция на ступеньку: экспонента с постоянной времени T, установившееся значение K.

### Колебательное звено

```
W(s) = K * w0^2 / (s^2 + 2*zeta*w0*s + w0^2)
```

Параметры:
- num = [K * w0^2]
- den = [1, 2*zeta*w0, w0^2]

При zeta < 1 — затухающие колебания, при zeta >= 1 — апериодический процесс.

### ПИД-регулятор

```
W(s) = Kp + Ki/s + Kd*s = (Kd*s^2 + Kp*s + Ki) / s
```

Параметры:
- num = [Kd, Kp, Ki]
- den = [1, 0]

## Пример схемы: анализ переходного процесса колебательного звена

Компоненты:
1. **Ступенька** (A=1.0, t0=0.0) — единичное воздействие
2. **Передаточная функция** (num=[4], den=[1, 0.5, 4]) — колебательное звено
3. **Временной график** — отображение

Связи:
```
Ступенька.y  →  ПФ.u
ПФ.y         →  График.y1
```

Параметры звена: K=1, w0=2 рад/с, zeta=0.125.
Ожидаемый результат: затухающие колебания с частотой ~2 рад/с, время затухания ~8 секунд.

## Код на встроенном языке (косвенная реализация через ODE)

```simintech
function TransferFunctionBlock
  input:
    double u;
  output:
    double y;
  var:
    double num[3] = {1.0, 0.0, 0.0};
    double den[3] = {1.0, 1.0, 0.0};
    int n = 2;  // порядок знаменателя
    int m = 2;  // порядок числителя
    double x[10];  // переменные состояния
    double dx[10]; // производные
    int i;
  init:
    for i = 0 to n-1 do
      x[i] = 0.0;
    end_for;
  begin
    // Производные: dx[i] = x[i+1], dx[n-1] = -sum(den[i]*x[i]) + u
    for i = 0 to n-2 do
      dx[i] = x[i+1];
    end_for;

    dx[n-1] = -den[0] * x[0];
    for i = 1 to n-1 do
      dx[n-1] = dx[n-1] - den[i] * x[i];
    end_for;
    dx[n-1] = dx[n-1] + u;

    // Выход: y = sum(num[i] * x[i])
    y = 0.0;
    for i = 0 to m do
      y = y + num[i] * x[i];
    end_for;

    // Интегрирование (явный Эйлер)
    for i = 0 to n-1 do
      x[i] = x[i] + dx[i] * getStepSize();
    end_for;
  end;
```

## Варианты использования

- **Фильтрация**: ФНЧ (апериодическое звено), ФВЧ (реальное дифференцирующее звено)
- **Коррекция**: последовательное включение передаточной функции для изменения частотных свойств системы
- **Моделирование объекта**: аппроксимация реального технологического процесса линейной моделью
- **Упреждение**: форсирующее звено (W(s) = T*s + 1) для компенсации инерционности

## Предостережения

- Порядок знаменателя должен быть больше или равен порядку числителя (n >= m), иначе модель физически нереализуема
- Коэффициенты задаются в порядке от старшей степени к младшей: [a_n, a_{n-1}, ..., a_0]
- При полюсах в правой полуплоскости система неустойчива — решение будет расходиться
- Высокий порядок (n > 10) может привести к численной неустойчивости — лучше разбивать на последовательность звеньев 1-2 порядка
- Все коэффициенты должны быть вещественными числами
- Для интегрирующих звеньев (полюс в нуле) убедитесь, что на входе нет постоянной составляющей — иначе выход уйдёт в бесконечность
- При дискретном моделировании шаг dt должен быть меньше наименьшей постоянной времени системы хотя бы в 5-10 раз
