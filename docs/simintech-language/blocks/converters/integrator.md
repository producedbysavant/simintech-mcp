# Блок «Интегратор» (Integrator)

Выполняет численное интегрирование входного сигнала по времени.

## Назначение

Блок «Интегратор» вычисляет интеграл входного сигнала по времени с заданным начальным условием. Это фундаментальный блок при моделировании динамических систем: любое дифференциальное уравнение сводится к набору интеграторов.

## Входы и выходы

| Тип | Имя | Описание |
|-----|-----|----------|
| Вход | u | Подынтегральная функция, double |
| Выход | y | Интеграл, double |

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| y0 | double | 0.0 | Начальное условие y(0) |
| reset | bool | false | Сброс по внешнему сигналу (если поддерживается вариантом блока) |

## Математическое описание

```
dy/dt = u(t)
y(0) = y0
```

В дискретной форме (метод Эйлера):
```
y[n+1] = y[n] + u[n] * dt
```

где `dt` — шаг интегрирования.

## Пример схемы: моделирование движения с постоянным ускорением

Компоненты:
1. **Константа** (value=9.81) — ускорение свободного падения
2. **Интегратор_1** (y0=0.0) — скорость v = integral(a * dt)
3. **Интегратор_2** (y0=0.0) — путь s = integral(v * dt)
4. **Временной график** — 2 входа (скорость и путь)

Связи:
```
Константа.y     →  Интегратор_1.u
Интегратор_1.y  →  Интегратор_2.u
Интегратор_1.y  →  График.y1  (скорость)
Интегратор_2.y  →  График.y2  (путь)
```

Ожидаемый результат: скорость растёт линейно (v = g*t), путь — квадратично (s = g*t^2/2). Через 10 секунд: v = 98.1 м/с, s = 490.5 м.

## Код на встроенном языке

```simintech
function IntegratorBlock
  input:
    double u;
  output:
    double y;
  var:
    double y0 = 0.0;
    double dt;
    double state;
  init:
    state = y0;
  begin
    dt = getStepSize();
    state = state + u * dt;
    y = state;
  end;
```

## Выбор метода интегрирования

SimInTech поддерживает несколько методов для интегратора:

| Метод | Точность | Устойчивость | Когда использовать |
|-------|----------|-------------|-------------------|
| Эйлера (явный) | O(dt) | Низкая | Быстрые расчёты, малый dt |
| Эйлера (неявный) | O(dt) | Высокая | Жёсткие системы |
| Трапеций | O(dt^2) | Средняя | Баланс точности и скорости |
| Рунге-Кутта 4 | O(dt^4) | Средняя | Высокая точность |

## Варианты использования

- **Моделирование накопителей**: уровень жидкости в резервуаре, заряд конденсатора, тепловая энергия
- **Сглаживание сигнала**: интегратор как фильтр низких частот (1/s)
- **Вычисление пути по скорости**: интегратор скорости даёт пройденный путь
- **ПИ-регулятор**: интегральная составляющая устраняет статическую ошибку

## Предостережения

- Интегратор без обратной связи дрейфует — любая постоянная составляющая на входе (даже численный шум) накапливается
- При моделировании в течение длительного времени ошибка интегрирования может нарастать — выбирайте метод точнее Эйлера
- Начальное условие y0 должно соответствовать физическому смыслу модели
- В жёстких системах явный метод Эйлера даёт расходящееся решение — используйте неявные методы
- Сброс (reset) сбрасывает состояние интегратора до y0, но не обнуляет выход мгновенно — требуется один шаг моделирования
