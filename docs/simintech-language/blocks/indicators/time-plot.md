# Блок «Временной график» (Time Plot / Scope)

Визуализирует сигналы в зависимости от времени на виртуальном осциллографе.

## Назначение

Блок «Временной график» отображает один или несколько сигналов на графике «амплитуда — время». Это основной инструмент визуализации при моделировании: позволяет увидеть переходные процессы, колебания, установившиеся режимы и аномалии в поведении системы.

## Входы и выходы

| Тип | Имя | Описание |
|-----|-----|----------|
| Входы | y1, y2, ..., yn | Визуализируемые сигналы, double |
| Выход | — | Нет выходов |

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| numInputs | int | 1 | Количество отображаемых сигналов |
| timeRange | double | 10.0 | Диапазон отображения по времени, с |
| yMin | double | -10.0 | Нижняя граница по оси Y |
| yMax | double | 10.0 | Верхняя граница по оси Y |
| autoScale | bool | true | Автомасштабирование |
| colors | string[] | — | Цвета линий для каждого сигнала |
| grid | bool | true | Отображение сетки |

## Настройка отображения

- Каждый сигнал отображается своим цветом
- Сетка настраивается (основная/вспомогательная)
- Возможно масштабирование области графика мышью
- Поддерживается режим «удержание» (persistence) для наложения последовательных запусков

## Пример схемы: сравнение входного и выходного сигналов фильтра

Компоненты:
1. **Синусоида** (A=1.0, f=2.0) — входной сигнал
2. **Передаточная функция** (num=[1], den=[0.2, 1]) — ФНЧ
3. **Временной график** (numInputs=2, timeRange=5.0, autoScale=true)

Связи:
```
Синусоида.y →  График.y1  (красный — вход)
ПФ.y        →  График.y2  (синий — выход фильтра)
```

Ожидаемый результат: красная синусоида с частотой 2 Гц и синяя синусоида той же частоты, но с меньшей амплитудой (из-за фильтрации) и сдвигом по фазе.

## Работа с несколькими сигналами

При отображении нескольких сигналов обратите внимание:

- Если сигналы сильно различаются по амплитуде, используйте отдельные графики или отключите autoScale и задайте yMin/yMax вручную
- Разные цвета помогают быстро идентифицировать сигнал на перегруженном графике
- Для переходных процессов устанавливайте timeRange, равный 3-5 постоянным времени системы
- Для установившихся режимов timeRange должен охватывать не менее 2-3 периодов основной частоты

## Варианты использования

- **Анализ переходного процесса**: подайте ступеньку и наблюдайте реакцию системы
- **Сравнение сигналов**: наложите вход и выход для оценки фазового сдвига и затухания
- **Поиск нелинейных искажений**: подайте синусоиду и проверьте форму выходного сигнала
- **Верификация модели**: сравните поведение модели с экспериментальными данными

## Предостережения

- График не сохраняется автоматически — экспортируйте данные через меню «Файл -> Экспорт» до закрытия схемы
- При большом timeRange и малом шаге моделирования график может тормозить — увеличьте шаг или используйте прореживание данных
- autoScale может ввести в заблуждение, если сигнал имеет выбросы — после выброса шкала изменится, и детали сигнала станут невидны
- Для анализа в частотной области используйте блок «Спектр» (FFT), а не временной график
- Если сигнал выходит за пределы yMin/yMax, он «обрезается» — увеличьте диапазон или включите autoScale
- На графике отображаются точки, соединённые прямыми — при большом шаге моделирования синусоида выглядит как ломаная линия
