# Блок «Цифровой индикатор» (Digital Display)

Отображает численное значение сигнала в цифровом виде в реальном времени.

## Назначение

Блок «Цифровой индикатор» показывает текущее значение сигнала в виде числа. Используется для контроля ключевых параметров модели: установившееся значение, максимальное/минимальное значение, значение в конкретный момент времени.

## Входы и выходы

| Тип | Имя | Описание |
|-----|-----|----------|
| Вход | in | Отображаемый сигнал, double |
| Выход | — | Нет выходов |

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| format | string | "%.3f" | Формат отображения (printf-стиль) |
| label | string | "" | Подпись над индикатором |
| precision | int | 3 | Количество знаков после запятой |

## Пример схемы: контроль установившегося значения

Компоненты:
1. **Ступенька** (A=5.0, t0=1.0) — входной сигнал
2. **Передаточная функция** (num=[2], den=[3, 1]) — апериодическое звено
3. **Цифровой индикатор** (format="%.2f", label="Установившееся значение")

Связи:
```
Ступенька.y  →  ПФ.u
ПФ.y         →  Индикатор.in
```

Ожидаемый результат: после завершения переходного процесса индикатор показывает значение 10.00 (K * A = 2 * 5 = 10).

## Форматы отображения

| Формат | Пример | Описание |
|--------|--------|----------|
| %.3f | 3.142 | Три знака после запятой |
| %.1f | 3.1 | Один знак после запятой |
| %.0f | 3 | Целое число |
| %.6f | 3.141593 | Шесть знаков после запятой |
| %e | 3.14e+00 | Экспоненциальная запись |
| %d | 3 | Целое (с округлением) |

## Варианты использования

- **Контроль уставки**: отображение текущего значения регулируемой величины
- **Отладка модели**: проверка промежуточных значений в контрольных точках схемы
- **Мониторинг пределов**: если значение приближается к критическому, можно добавить логическое сравнение с индикатором
- **Документирование результатов**: снимите показания индикатора в конце моделирования

## Предостережения

- Индикатор обновляется на каждом шаге моделирования, но при большом шаге число может «мерцать»
- Формат отображения влияет только на видимое значение — внутри используется полная точность double
- При очень больших/малых значениях используйте формат %e, иначе индикатор покажет "*****" (переполнение формата)
- На панели индикатора настройте размер шрифта так, чтобы число читалось — при автоматическом размещении текст может быть слишком мелким
- Индикатор не хранит историю значений — для записи данных во времени используйте блок «Запись в файл» или временной график
- При format = "%.0f" округление происходит по математическим правилам, а не в сторону нуля
