# Туториал 1: Твоя первая модель за 5 минут

Создай свою первую динамическую модель в SimInTech. Мы смоделируем, как нагревается чайник.

## Что ты узнаешь

- Как создать новую схему
- Как добавить и соединить блоки
- Как настроить параметры моделирования
- Как увидеть результат на графике

## Шаг 1: Создай новую схему

1. Открой SimInTech
2. Нажми **Файл -> Новый -> Схема** (или Ctrl+N)
3. Сохрани схему: **Файл -> Сохранить как...** → `teapot_model.prj`

## Шаг 2: Добавь блоки

Нам понадобятся 4 блока:

### Блок 1: Константа — мощность нагревателя

1. Нажми на панели блоков кнопку **«Источники»**
2. Выбери **«Константа»**
3. Перетащи на схему
4. Кликни дважды по блоку → введи `Value = 2000.0` (мощность 2000 Вт)

### Блок 2: Интегратор — накопление тепла

1. Нажми **«Математические» → «Интегратор»**
2. Перетащи на схему
3. Кликни дважды → введи `y0 = 20.0` (начальная температура 20°C)

### Блок 3: Сумматор — разница: нагрев минус потери

1. Нажми **«Математические» → «Сумматор»**
2. Перетащи на схему
3. Кликни дважды → введи `signs = "+-"`

### Блок 4: Временной график — увидеть результат

1. Нажми **«Индикаторы» → «Временной график»**
2. Перетащи на схему
3. Кликни дважды → `numInputs = 1`, `timeRange = 300`, `autoScale = true`

## Шаг 3: Соедини блоки

Подведи курсор к выходу одного блока → появится точка. Кликни и тяни линию к входу другого.

1. **Константа.y** → **Сумматор.in1** (мощность на вход)
2. **Сумматор.y** → **Интегратор.u** (разница мощностей на интегратор)
3. **Интегратор.y** → **График.y1** (температура на график)
4. **Интегратор.y** → **Сумматор.in2** (температура для расчёта потерь)

## Шаг 4: Добавь потери тепла

Наш интегратор считает чистую температуру, но нужно добавить теплопотери.

1. Кликни правой кнопкой на пустом месте → **«Вставить блок» → «Усилитель»**
2. Назови его `HeatLossCoeff`, задай `gain = -0.01`
3. Подключи: **Интегратор.y** → **HeatLossCoeff.u**
4. Подключи: **HeatLossCoeff.y** → **Сумматор.in2**

## Шаг 5: Настрой модель

1. Нажми **«Моделирование» → «Параметры...»**
2. Установи:
   - Время моделирования: 300 с
   - Шаг: 0.1 с
   - Метод: Эйлера (явный)
3. Нажми **OK**

## Шаг 6: Запусти!

1. Нажми **F5** или **«Моделирование» → «Запустить»**
2. Наблюдай за графиком

**Ожидаемый результат:** Температура растёт от 20°C, постепенно замедляясь. Через ~200 секунд она выходит на плато — мощность нагревателя сравнялась с теплопотерями.

## Что дальше?

Поздравляю — ты создал свою первую модель! Ты увидел, как:

- Константа задаёт мощность
- Интегратор накапливает тепло (температуру)
- Сумматор вычисляет разницу между нагревом и потерями
- Обратная связь создаёт эффект насыщения (равновесие)
