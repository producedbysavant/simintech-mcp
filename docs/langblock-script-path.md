# Скрипт блока «Язык программирования»: путь установки и узкие места

Дата замера: 2026-10-01. Объект: публичная поставка SimInTech 2.26.x, Windows, контур COM.

## 1. Что есть сейчас

**Уточнено 2026-10-16.** Штатная пара инструментов есть: `get_block_script` и
`set_block_script` (issue #23 закрыт; на main с 03.10.2026). Запись ниже —
история замера 01.10.2026: «штатного инструмента „прочитать/записать скрипт
блока“ в сервере нет».

Скрипт блока хранится как свойство объекта; отдельного метода COM для него нет —
он записывается свойством. Для скрипта страницы штатный путь был и есть (set page
script).

## 2. Рабочий путь (проверен)

1. Создать блок обычным способом.
2. Записать скрипт свойством и **обязательно пересобрать порты**:
   - `setprop(<блок>, "script", <текст>)`;
   - `reinitlangblock(<блок>)`.
   Оба вызова доступны через контур страницы (инструмент выполнения скрипта страницы).
3. Порты появляются **только после** пересборки: без второго шага провода остаются
   половинками, и это не сопровождается явной ошибкой.

## 3. Наблюдения

- Порты блока задаются **скриптом** (секции input/output), а не свойством:
  попытки задать список выходных типов через инструмент параметров схлопываются
  в пустой список, независимо от формы записи.
- Кавычки внутри строки скрипта передаются как `chr(34)`: удвоение кавычки в этой
  сборке даёт пустую строку, а не экранированную.
- Диагностика приходит позже: неверный формат объявлений не мешает вызову, но порты
  не появляются — расхождение видно только на следующем шаге.

## 4. Узкие места

- Два вызова в строгом порядке вместо одного; забытый второй шаг не даёт явной ошибки.
- Текст скрипта передаётся строкой: экранирование и переносы требуют осторожности.
- Контур сам не сообщает, пересобрались ли порты: явной ошибки нет, и различать
  «применилось / не применилось» можно лишь сравнением читаемого списка портов
  (`PortNames` доступен через COM) до и после — на этом стоит предложение §5.

## 5. Предложение (статус на 16.10.2026: выполнено, кроме третьего пункта)

**Реализовано 03.10.2026** (`get_block_script`/`set_block_script`):
- запись свойства → обязательный `reinitlangblock` → перечитывание текста; ответ
  называет число портов **до и после** — «молча не применилось» видно;
- чтение — снимком выгрузки, расчёт не запускается.

**Не делалось осознанно:** предварительная проверка формата объявлений до COM —
пересборка пинов измеренно неполна для объявлений с размером (`a[3]: array` даёт
2 входа вместо 3, замер 02.10.2026), и автоматическая «починка» ломала бы уже
настроенные блоки.

## 6. Напоминание о формате объявлений

- Каждый порт или переменная: `имя: тип` — **без кавычек**, явно.
- Типы: `double`, `integer`, `boolean`, `array` и `intarray` (массивы); порт-массив
  объявляется **без размера** (`a: array`) — форма с размером (`a[3]: array`)
  пересобрала порты неполно, 2 входа вместо 3 (замер 02.10.2026); для `intarray`
  в портах замера нет.
- Объявления разделяются точкой с запятой; каждую секцию закрывает `end;`.
- Порядок: входы → выходы → константы → переменные → секция инициализации → тело.
